# Competition notes

Source: https://comfy.org/open-source-higgsfield/ — consulted October 17, 2026.

- Build an application using the Comfy Developer Platform.
- Publish app code under an open-source license with setup instructions.
- Submission closes October 30, 2026, 9am Pacific Time.
- The demo should show the application working and explain its implementation. Innovation-category demos must explain the innovation.
- The Open Weights Only category excludes partner nodes and closed APIs. The optional VLM provider must also satisfy this requirement if entering that category.
- MiniMax H3 must be the core model to qualify for the H3 bonus.
- The public page also lists an inspiration named "Openjutsu", marked "Coming soon" when consulted. Our name was selected independently in this project conversation; do not imply official affiliation.

The "App requirements" and "Prepare your submission" headings did not expose detailed content in the retrieved page. Recheck the live page and submission form before entry.
